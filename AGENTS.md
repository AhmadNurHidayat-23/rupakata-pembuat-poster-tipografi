# RupaKata

- Hanya kerjakan aplikasi pembuat poster tipografi ini.
- Gunakan Laravel 13, Blade, CSS, JavaScript murni, dan Canvas.
- Seluruh antarmuka dan dokumentasi berbahasa Indonesia.
- Maksimal 300 baris per berkas kode sumber; lockfile dan hasil build dibuat otomatis.
- Jangan gunakan database, layanan eksternal, atau pustaka editor tambahan.
- Gunakan Canvas pratinjau sebagai sumber PNG agar hasil identik.
- Jalankan `php artisan test` dan `npm run build` setelah perubahan.
- Jangan commit `.env`, dependensi, kredensial, atau hasil build.
